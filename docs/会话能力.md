## 说明

- 能力"存在于 SDK"不等于"每台 Host / 每副眼镜都提供"。硬件相关能力在 `aios.json` 用 `capabilities` 声明，`toHostManifest` 会映射为 Host 清单里的 `hardwareRequirements`（`src/manifest.ts:76-89`）；会话里可通过 `onCapabilitiesChange` 看到实际能力。
- 需要用户授权的能力（麦克风、相机、位置、通知、日历、用户资料等）须在 `aios.json` 的 `permissions` 中声明，否则会得到 `PERMISSION_NOT_DECLARED`。
- 稳定性与空操作见 [稳定面与 v1 空操作](稳定面与v1空操作.md)。
