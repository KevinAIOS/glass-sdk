# 稳定面 vs v1 空操作

范围：`@aios/glass` 0.5.0、`aios-glass` 0.2.0、Native SDK，冻结于 `d5a93a3`。行号指**本次构建生成的** `packages/glass/src/`（由 `upstream/` 改名生成；改名不改变行数，只有 `modules/navigation.ts`、`modules/stream.ts` 在第 1 行多了一行说明注释）。

"稳定面"在这里是说：第一版开发者面里已经对到源码的候选与限制。正式冻结范围以 [体验编写面契约](体验编写面契约.md)（v0.1.0）为准，本页不另改冻结集。本页继续记录 v1 空操作与未核对限制，并不把整个 SDK 冻死。

## 3. 依赖另行配置的 Host 服务

`build.ts` 在生成时给两个文件加了第一行说明：

> `/** Requires a separately configured Host provider. The independent Host may reject service-backed operations with SERVICE_NOT_CONFIGURED. Importing this SDK does not enable a cloud service. */`

- `src/modules/navigation.ts:1`：导航。`computeRoute`（:410）、`reverseGeocodeRoad`（:438）、`placeAutocomplete`（:470）、`placeDetails`（:494）的注释写明在 "Host maps service" 中解析。`start`（:297）返回 ok 只表示守护进程接受了请求，不代表已建好路线（:295）。
- `src/modules/stream.ts:1`：直播。`startStream` 默认走 "managed" 模式，由 Host 配置的中继服务出流（`MANAGED_STREAM_START`，:159）；`direct` 模式直推你自己的 ingest URL（`STREAM_START`，:149）。
- 说明：`SERVICE_NOT_CONFIGURED` **只出现在这行注入的注释里**；`MiniappErrorCode`（`src/protocol.ts:398` 起）里没有这个码。Host 实际返回什么错误码，未能在此次抽出中核对（Host 不在抽出内）。

以下模块的注释表明它们依赖手机 / 云侧，但是否需要单独配置服务，**未能在此次抽出中核对**：`transcription`（"Phone forwards to the cloud STT layer"，`src/protocol.ts:179-181`；`transcription.ts:27`）、`translation`（`translation.ts:29`、`:40-44`）、`cloud`（只读状态，`cloud.ts:1-6`）、`speaker.speak`（有 `TTS_UPSTREAM_ERROR` 等错误码，`protocol.ts:416-421`）。

## 4. 未能核对到源码位置的候选

- **`stream` 的守护进程侧在 v1 未直播。** SDK 侧的 `stream.ts` 只是把 `MANAGED_STREAM_START` / `STREAM_START` 转发给 Host，没有任何"v1 未直播"的标记或空操作；守护进程（Host / 手机侧）源码不在本次抽出内。因此：**未能在此次抽出中核对到源码位置**。设备契约侧的情况见第 1 步 `glass-contract-v1/docs/STABILITY.md` §2.2（`aios.stream.*` 只是形状稳定，Host 可声明不可用）。

## 5. 以体验编写面契约为准的分桶

正式分类见 [体验编写面契约](体验编写面契约.md)。此处只提示不要再把「尚未定稿」当成现状：

- `@aios/glass/experience`、`defineExperience`、`aios.json` 的 `experience` 字段（`schema_version` 仍名为 `v1alpha`，`src/manifest.ts:39-63`、`:169`）、`registerApp(experienceDefinition)` 重载：已纳入该契约。其中声明、拟冻结的处理槽和本地 Session 面可依赖形状；`onMaterials` / `onSegment` / `onPeer` 等为形状保留不冻；Memory 为留云调用类型。
- `session.perception`、`session.miniapps`（"SYSTEM apps only"，`src/protocol.ts:202`）、`session.actions` 的跨应用调用，以及代码型的 `perception.*` / `agent.*`：契约中明确不进，不承诺稳定。
- `@aios/glass/protocol` 里的线协议枚举：是 SDK↔Host 的内部线格式，开发者不应直接依赖。
- `aios-glass account / publish / catalog`：依赖另行部署的目录服务，不属正路，契约中明确不进。
