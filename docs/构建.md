# 构建

工具链（本次实测）：bun 1.4.4、Node v24.22.1、npm 11.21.1。依赖由 `bun install` 安装（各包已有 `bun.lock`）。

```
cd packages/glass      && bun install && bun run build && bun run test
cd packages/glass-cli  && bun install && bun run build      # 会再调用一次 ../glass/build.ts 并 npm pack 出 assets/glass.tgz
cd packages/native-sdk && python3 build.py --sdk $ANDROID_HOME   # 需 JDK 17 + Android SDK
```

## 为独立构建做的改动

下面这些改动是为了让包在本仓库里尽量能独立构建。公开快照里的 `@aios/glass` `src/` 与 `dist/` 已经生成好；用于从 MentraOS 原文重新生成的上游输入不在本仓库，所以 `packages/glass` 的 `bun run build` 在本仓库无法重跑，请用 `bun test ./src` 验证已生成源码。

`packages/glass/build.ts`
- 源码根由仓库根 `../../..` 改为 `./upstream`。`upstream/` 放的是冻结快照里的 `mobile/modules/miniapp/src`、`cloud-v2/packages/protocol/src/languages.ts` 和根 `LICENSE`，相对布局不变，所以 `provenance.json` 的键与冻结时一致。
- 去掉从 `mobile/node_modules/eventemitter3` 复制依赖的步骤，改由 `bun install`。
- `tsconfig.build.json` 中 react 类型路径改为 `node_modules/@types/react`；`tsc` 改用 `node_modules/.bin/tsc`。
- 生成的 `NOTICE` 增加版权行（Copyright 2026 Kevin AIOS（陈子恒））与商标说明；原有来源说明保留。

`packages/glass/package.json`
- 加 `"private": true`；加 `scripts.build` / `scripts.test`（`bun test ./src`——必须带 `./`，否则 Bun 把 `src` 当路径子串，连 `upstream/.../src` 里未改名的原文件一起跑）；加 `devDependencies`：`typescript 5.9.3`、`@types/react ^19.0.0`（锁到 19.3.0）。版本仍 0.5.0，`exports`、`dependencies`、`bundledDependencies` 不变。

`packages/glass-cli/build.ts`
- 根改为仓库根 `../..`；contacts 模板来源改为 `examples/contacts`；LICENSE 取仓库根。
- 去掉从 `mobile/node_modules/typescript` 复制，改由 `bun install`。
- CLI 源码里的 `../../glass-contract/src/{catalog-client,packages}` 保持原样，构建时用一个 Bun 插件解析到 `build-inputs/glass-contract-src/`；`build.ts` 自己引用的 `network-policy` 也指向那里。

`packages/glass-cli/package.json`
- 加 `"private": true`。版本仍 0.2.0。
